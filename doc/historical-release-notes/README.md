# Historical release notes (upstream)

These directories contain release notes from the projects BurritoCoin Core
was forked from. They are kept for historical context and to make upstream
behaviour changes traceable, but they are **not BurritoCoin's release
history** and they reference URLs / contributors that are not affiliated
with BurritoCoin.

## `litecoin/`

Release notes for Litecoin Core 0.10.x through 0.21.4 — the upstream code
BurritoCoin Core forked from. Useful for understanding what was changed in
which Litecoin version, but the URLs, contributor lists, and version numbers
do not apply to BurritoCoin Core.

## BurritoCoin Core's own release notes

Once BurritoCoin Core publishes its first tagged release, that release's
notes will live alongside this directory in the parent `doc/` folder, named
`release-notes-<version>.md`. Until then, no canonical BurritoCoin Core
release exists.
