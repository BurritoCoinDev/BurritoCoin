# BurritoCoin Core release notes

This directory archives release notes for each tagged BurritoCoin Core
release. It is currently empty because BurritoCoin Core has not yet
published a tagged release.

When `v0.1.0` ships, its notes will be added here as
`release-notes-0.1.0.md`, and the release-process workflow described in
[`doc/release-process.md`](../release-process.md) will reference this
directory going forward.

For historical Bitcoin Core / Litecoin Core release notes (the upstream
projects this codebase was forked from), see
[`doc/historical-release-notes/`](../historical-release-notes/).
