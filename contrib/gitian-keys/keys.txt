# BurritoCoin release builder / developer keys
#
# This file lists the PGP fingerprints of the people who sign BurritoCoin
# Core releases. It is currently EMPTY because the project has not yet
# published a tagged, signed release. Once a release-signing key exists,
# its fingerprint and human-readable owner name will be added here, in the
# format:
#
#   <40-character GPG fingerprint>  <Name (optional context)>
#
# Until then, do NOT trust any "BurritoCoin" GPG signature — there is no
# canonical signer yet. Verify integrity of source via the GitHub repository
# at https://github.com/BurritoCoinDev/BurritoCoin and any binaries via
# checksums published alongside their GitHub Release.
#
# This file previously inherited a list of Bitcoin Core developers from the
# upstream Litecoin project, who have NO connection to BurritoCoin and do
# NOT sign its releases. Those entries have been removed to prevent
# misleading anyone trying to verify a build.
