🪟 Mining on Windows

About ten minutes on Windows 10 or 11 (64-bit). Download one file, create a wallet, and press Start Mining — the wallet has a miner built in. No command line, and usually no config files (Step 4 covers the one exception).

Step 1 of 4

Install BurritoCoin Core

1

Download the wallet

One self-contained file: full node, wallet, and miner in one. No installer, no extra DLLs.

Download for Windows burritocoin-qt-win64.exe · v0.21.4 · 33 MB

Save it somewhere you'll remember, e.g. C:\BurritoCoin.

If your browser holds the download with a message like "isn't commonly downloaded" — Edge and Chrome do this for new, unsigned programs — open your downloads list with Ctrl+J, click the file's ⋯ menu and choose Keep. In Edge, then click Show more → Keep anyway.

2

Verify the download (recommended)

Open PowerShell, cd to the folder where you saved the file, and run:

Get-FileHash .\burritocoin-qt-win64.exe -Algorithm SHA256

The SHA256 of the current build should match:

3890885D10A7E3BC6A43A95A79D0904DBF64090BEBFDF6C51F67B5D934263AF2

If it doesn't match, the download is corrupted, tampered with, or this page is out of date relative to the repository — delete the file and re-download before running it.

Windows SmartScreen warning? The wallet isn't code-signed yet, so on first launch Windows may show "Windows protected your PC". Click More info → Run anyway. The SHA256 above is how you know the file is untampered before you get this far.

Prefer the command line? There's no pre-built burritocoind.exe — build the command-line tools from source in WSL2 and follow the Linux guide, which mines with the node's built-in miner. To build natively instead, see doc/build-windows.md.

Step 2 of 4

Create and Protect Your Wallet

1

Start BurritoCoin Core

Double-click burritocoin-qt-win64.exe. The first time, it asks where to keep its data: choose Use the default data directory and click OK. That's %APPDATA%\BurritoCoin, and the whole blockchain is only a few megabytes today.

If Windows Firewall asks whether to allow BurritoCoin Core, allowing it on private networks is enough — that only lets other nodes connect to you. Your own connections out to the network work either way.

2

Create your wallet

A Welcome to BurritoCoin box appears: click Create My Wallet. (Clicked "I'll do it later"? Use File → Create Wallet….)

In the Create Wallet dialog, give it a name, tick Encrypt Wallet, and choose a long passphrase. Leave Advanced Options alone.

Write the passphrase down and keep it safe. Nobody can reset it. Without it, the coins in this wallet can never be spent.
3

Back it up

Use File → Backup Wallet… and save the copy somewhere off this computer — a USB stick, or a cloud folder. For a paper backup as well, File → Back Up Recovery Key… shows a key you can write down. The wallet's ⚠ Back up wallet reminder changes to ✔ Backed up once it's done.

If you encrypt later instead (Settings → Encrypt Wallet…), back up again afterwards: encrypting generates a new recovery key, and older backups won't include addresses made after it.

Step 3 of 4

Let It Sync

1

It connects on its own

There's nothing to configure — the wallet finds the network through seed.burritoco.in automatically. Hover over the network icon at the bottom right: you want 1 active connection or more.

2

Read the "out of sync" notice correctly

While it catches up, the wallet shows a notice starting "Recent transactions may not yet be visible…". The chain is small, so catching up takes a minute or two. To be sure you're done, open Window → Information (Ctrl+I) and compare Current block height with the latest block on explorer.burritoco.in. When they match, you're synced — click Hide this notice.

If nobody has mined for a while, the wallet can't tell a quiet network from a slow download. Once the newest block is more than about 90 minutes old, the notice keeps showing even when you're fully synced: Number of blocks left reads "Unknown. Syncing Headers (…%)" and the status bar says "Syncing Headers (…%)", with a low percentage. That's expected. The matching block height is the signal that matters — and as soon as anyone mines a new block, the notice clears for everyone.

Connected and synced before you mine. A wallet with no connections would mine its own private copy of the chain, and the rest of the network would never accept those blocks. Check for at least one active connection first.
Step 4 of 4

Start Mining

1

Press Start Mining

Open the Mine tab. Choose how many Processor cores to use (or tick Use all cores), then press Start Mining. The tab shows your current speed, blocks found this session, and an estimated time to a block.

Mining runs only while the wallet is open. Press Stop Mining whenever you like. Pause while on battery power and Pause while I'm using the computer keep it out of your way.

2

If it says "BurritoCoin is still syncing"

The Mine tab won't start while the wallet thinks it's catching up — and when nobody has mined for over a day, it thinks that even once you're fully synced (Step 3). If your block height already matches the explorer, tell the wallet a quiet chain is fine:

  1. Settings → Options… → Open Configuration File. It opens burritocoin.conf; if Windows asks which app to use, pick Notepad.
  2. Add this line, then save: 
    maxtipage=315360000
  3. Close the wallet with File → Exit, open it again, and press Start Mining.

Your first block un-freezes the chain for everyone else. Only do this after your height matches the explorer: the setting switches off the wallet's "still syncing" check, which is what stops you mining before you've caught up. It stays on every time you open the wallet, so after the wallet has been closed for a while, check your height against the explorer again before pressing Start Mining — or delete the line once other people are mining regularly.

3

Watch the rewards arrive

Every block you find pays 10 BRTO straight into your wallet — you'll see it on the History tab. New coins are immature until 100 more blocks have been mined on top of them: about four hours at the network's 2.5-minute target, and longer while few people are mining. After that they're yours to spend.

Want more speed, or to mine with a graphics card? Tick Use an external miner program on the Mine tab and follow the Set up an external miner guide linked there. The wallet runs a private mining connection on your own computer for the miner to talk to. Don't point a miner at the wallet's RPC port directly instead — stock miners like cpuminer-opt don't support MWEB, BurritoCoin's privacy extension, so the node refuses to hand them work. The Mine tab deals with the node on the miner's behalf.
Troubleshooting

When Something's Off

"Windows protected your PC" when I open it

The wallet isn't code-signed yet. Check its SHA256 against Step 1, then click More info → Run anyway.

The download never showed up

Your browser may be holding it. Press Ctrl+J, find burritocoin-qt-win64.exe, and choose Keep from its ⋯ menu (Edge: then Show more → Keep anyway).

The "out of sync" notice won't go away

Open Window → Information and compare Current block height with the explorer. If they match, you're synced — the notice (and "Syncing Headers" in the status bar) is about the age of the newest block, not your wallet; see Step 3.

My block height stays at 0

Hover over the network icon. With no connections, check that nothing on your network blocks outgoing connections to port 9227. With a connection and still 0 after 15 minutes, don't mine — open an issue on GitHub.

The Mine tab says "BurritoCoin is still syncing."

If your block height matches the explorer, nobody has mined for over a day — see Step 4. If it doesn't match, you aren't synced yet: give it a few minutes, or see "My block height stays at 0" below.

The Mine tab says "Open a wallet before mining."

Create one with File → Create Wallet…, or open an existing one from File → Open Wallet.

I found a block but can't spend the coins

Newly mined coins are immature for 100 blocks. They become spendable on their own; nothing needs doing.

Where are my wallet files?

File → Show Wallet File Location… opens the folder. By default everything lives under %APPDATA%\BurritoCoin.
