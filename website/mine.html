Before You Start

What You Should Know

Mining is the process of running a program that does math problems for the network. When your computer solves one, the network rewards you with newly-created BurritoCoin and you've also helped confirm transactions for everyone else.

BurritoCoin uses the same mining algorithm as Litecoin, called Scrypt. But the node only hands out mining work to miners that support MWEB, BurritoCoin's privacy extension, and ordinary Scrypt miners don't. BurritoCoin Core mines for you instead: the Windows wallet has a Mine tab, and on macOS and Linux the node has a built-in miner you run from the command line. You don't need special hardware — a regular CPU works fine while the network is small.

Reality check: Right now there are essentially no other miners on the network, and difficulty is low. A single laptop has a real chance of finding blocks. That also means the chain only moves when someone is mining, so by mining you're keeping it alive.

Got a GPU or ASIC? A faster CPU miner (cpuminer-opt) or an NVIDIA card (ccminer) can mine through the Windows wallet: tick Use an external miner program on its Mine tab, and the wallet builds the blocks while the miner does the hashing. That connection only accepts miners running on the same computer, so ASICs and separate mining rigs can't use it. They'd need a Stratum pool server that handles MWEB, and there isn't a public one for BurritoCoin yet. Pointing any of them straight at a node's RPC port doesn't work: the node refuses requests for work from miners without MWEB support. If you're just curious, start with your CPU.
The Big Picture

What You'll Be Setting Up

Every guide follows the same path:

1

Install BurritoCoin Core

The software that connects you to the BurritoCoin network, holds your wallet, and does the mining. On Windows it's a single download; on macOS and Linux you build it from source.

2

Create and back up a wallet

This is where your mining rewards land. Encrypt it with a passphrase and keep a backup somewhere other than your computer.

3

Let it sync

Your copy of the chain catches up with everyone else's. It's small, so this takes a minute or two.

4

Start mining

Press Start Mining on the Windows wallet's Mine tab, or start the built-in miner with one command on macOS or Linux. Nothing else to install.

5

Collect your rewards

Each block you find pays 10 BRTO into your wallet. They're spendable once 100 more blocks have been mined on top.
